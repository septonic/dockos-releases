# DockOS downloads

Public developer installers for [DockOS on Odd Mac](https://odd-mac.vercel.app/products/dockos).

The application repository is private. This repository hosts versioned installers, SHA-256 checksums and release metadata so downloads do not require GitHub access.

DockOS 0.5.22 (build 28) supports Apple silicon and macOS 14 or later. It was supplied as a compiled app; original source was not included. The original ZIP is preserved unchanged in the private app repository's supplied-build release.

Developer installers are Developer ID signed, but not Apple notarized. See the product page for permissions and compatibility. Bundled third-party notices retain their original terms.
